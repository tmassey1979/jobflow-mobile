## Generation / conversion steps

1. User approved Direction B (Signal Mark) and the adaptive-icon concept (charcoal BG + blue dual-chevron).
2. Foreground geometry was simplified into clean SVG paths suitable for Resizetizer and small-size legibility.
3. MAUI `MauiIcon` with `ForegroundScale="0.65"` and `Color="#1A1A1A"` produces Android adaptive mipmaps at build time.
4. Splash uses the same mark centered on a charcoal field via `MauiSplashScreen`.
5. Empty-state uses a muted Signal Mark inside a soft card for the jobs list.
6. No raster intermediates required; PNGs are generated by the MAUI build if needed.
